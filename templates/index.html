APEDA Exporter's Directory

Search India's APEDA-registered agri-food exporters by state, product and exporter type.

Live data from APEDA's own directory backend, queried server-side by this tool · source page: apeda.gov.in/exporter-directory (unofficial mirror, not affiliated with APEDA)

Data limits, read before filtering: APEDA's directory has no nationwide search — a state is required. It also has no official district field (only city/pincode) and no exporter-website field (only email/mobile) — so "District" below is a free-text match against each exporter's city and address, and there is no website column to filter or show.

Fields shown come directly from APEDA's registered-exporter records: exporter name, key person, address, city, state, pincode, email, mobile, exporter type/status, and total registered export quantity & value (all-time, across all products, not specific to the selected product filter). This tool runs locally and makes no changes to APEDA's data.
